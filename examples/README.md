# RC-FormWork mock-up project

Import `RC-FormWork-Mockup-Project-v0.7.json` from the app's **นำเข้าโครงการ** control.
The import creates a new project and assigns new project and case IDs.

`Project-Example-v0.7.json` is the complete walkthrough named **Project Example**. It contains
the same ten cases with every legacy, beam, slab and wall field populated, catalogue section IDs,
and reference notes for ACI PRC-347, APA V345, PAP-TIS107, the Design Form Work timber table,
the Ringlock research file, and the Closure Pack Form Tie bridge. The app also creates this project
from **สร้าง Project Example** without importing a file.

The file contains ten editable demo cases: two each for footing, column, wall, beam and slab.
It uses the app's existing demo presets for Beam, Slab and Wall; dimensions are illustrative.
All cases are unconfirmed. Tie, brace, anchor and shoring capacities stay unknown at zero, so
the screening result must remain incomplete or no-go. This file is for UI and workflow practice,
not for engineering decisions or construction.

The Ringlock/Form Tie notes are evidence pointers only. Unknown equipment capacities remain `0` and
must be replaced by the actual supplier certificate, configuration, support/soil design basis and
engineer review before any construction release.
