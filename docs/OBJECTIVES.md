# วัตถุประสงค์ของแอป (ฉบับแก้ไขโดย Owner)

เอกสารนี้แทนที่ขอบเขต "ฐานราก/เสา" ใน Master Prompt 1.1 ด้วยระบบแบบหล่อ 5 แบบ ใช้เป็นเกณฑ์ประเมิน
requirements matrix ต่อจากนี้ ข้อกำหนดด้านวิธีทำงาน (deterministic, ห้ามเดา, INCOMPLETE, NO_GO) ยังคงเดิม

## เป้าหมาย

สร้างแพลตฟอร์มออกแบบแบบหล่อคอนกรีต (ไม้อัด + เหล็ก RHS/SHS/C) ที่คำนวณแบบ deterministic
ตรวจสอบย้อนกลับได้ โดย AI ช่วยอ่านแบบและเสนอทางเลือกเท่านั้น ห้าม AI คำนวณค่าออกแบบหรืออนุมัติ

1. รับแบบ PDF/สเก็ตช์ → AI อ่านมิติ → ผู้ใช้ยืนยัน → เสนอการจัดวาง → คำนวณละเอียด → รายงานและแบบติดตั้ง
2. ระบบแบบหล่อ 5 แบบแยกชัด ห้ามสลับกันโดยไม่แจ้ง
3. ตรวจครบ: ไม้อัด คร่าว คานรัด/คานรับคร่าว ไทร์ มุม ค้ำยัน/Shoring จุดต่อ เสถียรภาพ;
   สิ่งที่ยังไม่มีวิธีหรือข้อมูลต้องแสดง INCOMPLETE ห้ามเดา
4. รายงานคำนวณแบบคลาสสิก สูตร-แทนค่า-ผล-ที่มา และแบบ A3 จาก snapshot เดียวกัน
5. Firebase หลายโครงการ, RBAC, snapshot ที่แก้ไม่ได้, audit, workflow ตรวจ/อนุมัติ/ออกแบบ

## ระบบแบบหล่อ 5 แบบ

| # | ระบบ | เส้นทางแรง | องค์ประกอบที่ต้องออกแบบ |
|---|---|---|---|
| 1 | ฐานราก (ไทร์ทะลุ) | แรงดันคอนกรีต → ไม้อัด → คร่าว → คานรัดคู่ → แผ่นรอง/นัต → ไทร์ทะลุระหว่างผิวตรงข้าม | ไม้อัด คร่าว คานรัด ไทร์ แผ่นรอง มุม; รูปสี่เหลี่ยม/ตัว L/หลายเหลี่ยม |
| 2 | เสา (yoke ภายนอก) | แรงดัน → ไม้อัด → คร่าว → yoke/เฟรมภายนอก → อุปกรณ์มุม | ไม้อัด คร่าว yoke อุปกรณ์มุม ค้ำยัน เสถียรภาพเต็มความสูง; ห้ามถือแท่งมุมเป็นไทร์ทะลุ |
| 3 | คาน | **ด้านข้าง**: แรงดัน → ไม้อัด → คร่าว → คานรับคร่าว/คานรัด → ไทร์หรือค้ำ; **ท้องคาน**: น้ำหนักคอนกรีต+งาน → ไม้อัด → คร่าว (joist) → คานรับคร่าว (bearer) → Shoring | แบบข้างและแบบท้องแยกตรวจ แล้วรวมแรงลง Shoring |
| 4 | พื้น | น้ำหนักคอนกรีต+งาน → ไม้อัดท้องพื้น → คร่าว → คานรับคร่าว → Shoring | ไม้อัด คร่าว คานรับคร่าว Shoring (U-head, standard, ledger, brace, base) และเสถียรภาพด้านข้าง |
| 5 | ผนัง | เหมือนเสาแต่มีสองด้าน: แรงดัน → ไม้อัด → คร่าว → คานรัด → ไทร์ทะลุ และ/หรือ ค้ำยัน/เฟรม | ไม้อัด คร่าว คานรัด ไทร์ มุม ค้ำยัน เสถียรภาพ; ผิวที่ไม่มีคู่ตรงข้ามต้องมีค้ำ |

ทุกระบบ: แรงที่แมปต้องอนุรักษ์ผลรวมแรงและโมเมนต์ของแรงดัน ใช้พิกัดจริงของสมาชิกและจุดรองรับ
ไม่ตัดช่วงปลาย ไม่ใช้ค่าเฉลี่ยแทนแรงจริง และกำลังรับแรงทุกค่ามาจากหลักฐานที่รีวิวแล้วเท่านั้น
